# Design insert

The subject is `.parsec/spec.md` and `.parsec/tasks.md`; `.parsec/context.md` names the rubric and each evidence file. Check the task list against the spec, and every fenced block against the code it names in the tree: a task whose code cannot work where it lands is a finding. Check the file map, the consumes and produces chain, and that every Behaviour case traces to the Goal and to a task's test or named check.
