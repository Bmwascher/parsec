# Design insert

The subject is `.parsec/spec.md`; `.parsec/context.md` names the rubric and each evidence file. The feature has no task list: after the go, the session writes the code and its tests from this spec, test first. Review the spec: behaviour left open, contradictions, cases it does not decide, a file, name, signature or call site in its Design section that does not exist or cannot work where it lands in the tree, and anything that would make correct code impossible. Check that every Behaviour case traces to the Goal and to a test or named check in its Testing section. A missing implementation is not a finding.
