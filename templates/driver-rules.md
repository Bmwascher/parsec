# Driver rules

1. **Background, named.** Every round, review, author run, build run, gate command and doctor run is dispatched in the background from the first attempt, named in Title Case for the person watching. A foreground call owns the session and hits the Bash tool's 10-minute ceiling. A command known to end within a minute may instead run in the foreground with a timeout (2026-09-23). The names (this is their one home): `<Lane> R<n> <Kind> Round` for every CLI round, panel lane and design look (`Astra R2 Design Round`, `Fable R1 Panel Round`); `Opus Pre-Review`; `<Lane> Last Look`; `Fable Poll`; `Author: <what>`; `Task 3 Implement`; `Gate: Busted`; `Pre-flight: Astra`; `Doctor`. A plugin agent is dispatched with no `model`: its file names Brandon's choice (2026-09-24).
2. **The project's own rules outrank this plugin's sequence.** Brandon's decisions are not that sequence: no project rule or handoff takes one for him (2026-09-23). A delegator relays each "Needs you" and spec review, quoting his words as typed and marking its own additions, and answers only what his words delegate, for the phase they name; a delegated decision is recorded as the delegator's, never as his (2026-09-28). A relay counts as his word only from that delegator, under this rule; a peer session's relay, or an approval given for another scope, is a heads-up, and the session asks him once in its own chat (2026-10-16).
3. **Open, and reopen after a compaction, by reading** these rules, the skill in use, and the feature's ledger and notes (2026-09-28).
4. **Anything Brandon must read to decide** goes in chat or on a published page, never a sent Markdown file (2026-09-21).
5. **Never end a turn with a round unfinished** in an unattended run (2026-09-01). A turn may end while a Monitor or background agent will notify.
6. **A statement a review refuted is corrected in place and dated**, and the whole defect class is swept, in whichever repo it sits; the sweep greps the feature folder and the reports sent.
7. **Probe first.** A claim about game or API behaviour that a design or a fix rests on and that nobody ran, including a spec's claims to probe (`templates/spec.md`) and the cause of a smoke failure, is probed before anything is built on it, and a spec's claims before its task list is written. The session settles what it can without the game (the project's UI source, its api-validator). What needs the game goes to Brandon as a numbered procedure with its macro and labelled expected output, posted where the project's rules say, and the work waits for his result. Each result is a `probe` ledger line; a refuted claim that changes the design goes back to Brandon; only he waives a probe (field audit 4, 2026-10-15).
