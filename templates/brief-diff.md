# Diff insert

The package (`commits.txt`, `stat.txt`, `diff.patch`, the evidence files) is your view of the branch. An implementer's report is a claim. Open code outside the diff only for a risk you can name. A defect that was there before blocks only when it breaks the same named invariant the branch is fixing AND sits in the files this brief lists; anything else is a follow-up, and a PASS names every follow-up it leaves open. When the feature has an approved design, check the diff against it and the amendments `context.md` lists.
